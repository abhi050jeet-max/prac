# Abhi's Portfolio

A modern, animated personal portfolio website built with HTML, CSS and JavaScript.

**Live site:** https://abhi050jeet-max.github.io/prac/

## About
I'm a BTech Computer Science student in India. I build full-stack apps with Spring Boot on the backend and React on the frontend. This portfolio showcases my skills and projects.

## Features
- Smooth scrolling with Lenis
- Scroll animations and hero text reveal with GSAP
- Interactive 3D background with Three.js
- Horizontal-scrolling projects section
- Fully responsive (mobile, tablet, desktop)
- Respects reduced-motion settings

## Tech Stack
- **Languages:** HTML, CSS, JavaScript
- **Libraries:** GSAP, ScrollTrigger, Lenis, Three.js
- **Hosting:** GitHub Pages
